*vs-diff.txt*  VS Code-style git SCM panel for Neovim

==============================================================================
INTRO                                                           *vs-diff*

vs-diff shows unstaged, staged, and conflicted files in separate trees.
Select a file to open a side-by-side diff, then stage, unstage, or discard
from the panel.

It hosts itself in neo-tree when that plugin is installed, in the Snacks
explorer sidebar when explorer is enabled, or in a built-in panel otherwise.
Override with `opts.backend`.

==============================================================================
COMMANDS                                               *vs-diff-commands*

:VsDiff [focus|show|toggle|close]                      *:VsDiff*
    Open or focus the SCM panel. `toggle` hides it if it is already visible.

:VsDiffClose                                           *:VsDiffClose*
    Close the side-by-side diff windows opened by vs-diff.

==============================================================================
MAPPINGS                                               *vs-diff-mappings*

<CR>        Open a diff, edit the commit box, or activate Generate / Commit / Push / Pull
D           Toggle float vs split diff
Q           Close the current diff window
o           Open the working-tree file
s           Stage file / folder / section
u           Unstage file / folder / section
x  or  d    Discard unstaged changes (confirms)
S           Stage all
U           Unstage all
X           Discard all unstaged changes
a           Toggle tree vs flat list
g           Generate a commit message from staged changes (CLI or API)
c           Commit, or push / pull / sync when the working tree is clean
R           Refresh
q           Close the panel

Visual-mode s / u / x apply to the selected nodes.

When the working tree is clean, Commit becomes Push, Pull, Sync
Changes, or Publish Branch based on ahead/behind vs upstream.

==============================================================================
SETUP                                                     *vs-diff-setup*

>lua
    require("vs-diff").setup({
      confirm_discard = true,
      view = "tree",
      backend = "auto",
      panel = { position = "left", width = 36 },
      diff = { layout = "vertical" },
      ai = { backend = "auto", env = "XAI_API_KEY", model = "grok-4.5" },
    })
<

AI generate (`g` / Generate) uses a local CLI if one is on PATH:
grok, claude, copilot, codex, gemini, llm, or `gh copilot`. Otherwise it
falls back to the SpaceXAI HTTP API (`XAI_API_KEY`). Override with
`opts.ai.backend` or `opts.ai.command`.
